# Feature documentation

One Markdown file per feature, named after the feature (`redirects.md`, `contact-form.md`, `backup.md`). The folder listing is the index: do not add a list of features here, so two pull requests that add a feature never edit the same line.

Each file starts with `# Title`, then says what the feature does, its routes or options, limits and security notes, and what is not built yet (with the queue id).
