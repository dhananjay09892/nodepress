# Docker and deploy templates

The `Dockerfile` builds the whole repository (server, admin, themes, plugins) and runs `node apps/server/dist/main.js` as the unprivileged `node` user. All data lives in `/data` (a volume): the SQLite database (`DATABASE_URL=file:/data/nodepress.db`), uploads (`MEDIA_DIR=/data/media`) and installed plugins (`PLUGINS_DIR=/data/plugins`). The image listens on `PORT` (3000) and has a health check on `/api/health`. Pass the usual settings as environment variables: `ADMIN_EMAIL` and `ADMIN_PASSWORD` (needed on first start), `SITE_NAME`, `SITE_URL`, `TRUST_PROXY=true` behind a reverse proxy, and `COOKIE_SECURE=false` only to try it over plain `http://localhost`. Try it with `docker build -t nodepress . && docker run -p 3000:3000 -v nodepress-data:/data -e ADMIN_EMAIL=you@example.com -e ADMIN_PASSWORD=... -e COOKIE_SECURE=false nodepress`.

`docker-compose.yml` runs NodePress with PostgreSQL 16: copy `.env.example` to `.env`, set `POSTGRES_PASSWORD`, `ADMIN_EMAIL` and `ADMIN_PASSWORD` (compose refuses to start without them), then `docker compose up -d`. The site waits for the database to be healthy. Empty `CONTACT_SECRET` or `WEBHOOK_SIGNING_KEY` values are treated as unset.

`deploy/` has templates for Railway (`railway.json`), Render (`render.yaml`, copy to the repository root) and Fly.io (`fly.toml`, copy to the repository root); each builds the same Dockerfile, uses `/api/health` as the health check and keeps `/data` on a persistent disk or volume. They have not been tried on the real services yet (N63). CI builds the image, runs it, logs in, checks it runs as a non-root user and healthy, then starts the compose stack with PostgreSQL and checks it too.

Container disks disappear on redeploy unless `/data` is a persistent volume. To keep uploads somewhere else, set `MEDIA_STORAGE=s3` and the `S3_*` variables listed in [s3-storage.md](s3-storage.md) (`S3_BUCKET`, `S3_REGION`, `S3_ENDPOINT`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_PUBLIC_URL`); `docker-compose.yml` and `.env.example` pass them through.
