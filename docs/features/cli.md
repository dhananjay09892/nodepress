# Command line

The **`nodepress` command line** (`@nodepress/cli`, `packages/cli`; run it with `node packages/cli/dist/bin.js` until it is published) has no dependencies of its own: `nodepress migrate` applies the database migrations (`DATABASE_URL` or `--database-url`); `nodepress dev [--port 3000]` starts the built server and restarts it when files change; `nodepress plugin create <name>` writes a plugin (`plugin.json`, `package.json`, a plain-JavaScript `index.js` that needs no build step, and a README) into `./plugins-installed`; `nodepress plugin check [folder]` validates `plugin.json` and loads the entry with the same code the server uses; `nodepress plugin pack [folder]` writes `<name>-<version>.zip`, ready for the admin's Plugins screen (it leaves out `node_modules`, `.git` and other zips); `nodepress theme create <name>` writes a TSX theme that mirrors Starter into `./themes`. Exit codes: 0 ok, 1 failed, 2 a usage mistake. CI scaffolds a plugin, checks it and packs it on every run.
