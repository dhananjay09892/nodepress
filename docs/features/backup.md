# Backup and export

Backup and export: `GET /api/v1/backup/export` (`manage_options`) downloads the whole site as one JSON file: content of every status (trash included) with custom fields and term assignments, all terms, the site settings and the names of the authors. It holds no users' passwords, tokens or secrets. `POST /api/v1/backup/import` (`application/json`, up to 256 MB) reads such a file back: it is validated first (a bad file changes nothing), then terms (parents first), content (parents first, new ids, slugs kept unique), custom fields, terms and the settings are written. Existing content is never changed or deleted, so importing into a site that already has the same posts adds copies. Items go to the user whose email matches the author in the file, else to the user running the import. Custom fields that point at media (`featured_image`) are left out, and files, menus, widgets and redirect rules are not part of this first slice (N61).
